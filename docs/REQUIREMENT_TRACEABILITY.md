# Hospital Vision — Requirement Traceability Matrix (RTM)

## Phase 1: Full Codebase Requirement Reconciliation + P0 Security & Operational Fixes

This document tracks all core requirements from the Hospital Vision source documents against the actual implementation in the current codebase (`React + Vite + Tailwind CSS` frontend, `Node.js + Express + MongoDB/Mongoose` backend).

### Status Taxonomy:
- 🟢 **COMPLETE**: Fully implemented in frontend UI, backend API, database schema, with tenant/branch isolation and automated tests passing.
- 🟡 **PARTIAL**: Implemented in part; core functions exist but specific secondary workflows, filters, or edge-cases remain to be implemented.
- 🔴 **MISSING**: Not implemented in code; route or UI does not exist yet.
- 🔴 **BROKEN**: Exists in code but unusable due to contract mismatch, uncaught exception, or regression.
- ⚠️ **NOT VERIFIED**: Code exists but lacks automated or manual verification against live database.
- 🔵 **CONFIGURABLE / OPEN DECISION**: Implementation depends on hospital-specific policies, commercial tariffs, or external regulatory APIs left intentionally configurable.

## Open Decisions & Hospital-Specific Configurable Elements

1. **Hospital Tariffs & Clinical Policies**:
   - Tariffs for consultation, ICU per-day rates, emergency triage surcharges are preserved as configurable parameters in tenant settings and invoice line items.
2. **Payment Gateway Provider Selection**:
   - The Payment Gateway service supports adapter architecture (`Razorpay`, `Stripe`, `Cashfree`, `Offline`). The specific provider credentials remain an open decision per hospital entity.
3. **ABDM Sandbox Gateway Credentials**:
   - The FHIR R4 translation and milestone data structures are complete. Live communication with the National Health Authority (NHA) ABDM bridge requires hospital registration client IDs.
4. **Third-Party SMS/WhatsApp Providers**:
   - The Notification Service supports SMS/Email/WhatsApp notification adapters (`Twilio`, `Gupshup`, `ConsoleFallback`). Active API keys are hospital/tenant configurable.
